# Results Directory Structure

- phase0/: Frozen Phase 0 baseline specs, proxy check csv, and reference metrics.
- R/: Random arm run results (trials, final json, summary).
- L-naive/: LLM naive arm run results.
- L-FDR/: LLM online-FDR arm run results (7B model).
- R-naive/: R-naive arm run results.
- L-FDR-3B/: LLM online-FDR arm run results (3B model).
- L-FDR-14B/: LLM online-FDR arm run results (14B model).
- phase3/: Unsealed final evaluation results and logs.
- contamination_probe_answer.json: Model contamination probe responses.
